An interactive, cyber-slate themed **Data Science & Machine Learning Engineering Portfolio** built with HTML5 Canvas, Tailwind CSS, and Vanilla JavaScript. Designed to showcase end-to-end ML systems, MLOps deployment workflows, and live model inference simulations.

---

## ✨ Key Features

- **🧠 Mouse-Reactive Neural Network Canvas:** Dynamic particle-and-edge background rendered via HTML5 `<canvas>` that responds to cursor proximity.
- **💻 Interactive Hero CLI Terminal:** Functional bash-style shell (`whoami`, `skills --top`, `projects --list`, `status`, `contact`) for quick recruiter navigation.
- **⚡ Live ML Model Sandbox:**
  - **House Price Estimator:** Real-time valuation simulator with dynamic SHAP feature contribution bars (Area, Location Multiplier, Build Quality).
  - **Fake News NLP Classifier:** Interactive TF-IDF & Passive-Aggressive headline verifier with token extraction and confidence scoring.
- **🏗️ System Architecture Blueprints:** Interactive modals breaking down the 4-stage data ingestion, feature engineering, modeling, and cloud deployment pipelines for each project.
